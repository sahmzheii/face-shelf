FACE SHELF

Data Deletion

คำแนะนำการลบข้อมูล · User data deletion instructions

เมื่อลบข้อมูล ระบบจะลบ Page access token, session, โพสต์, รูปสินค้า และสถานะทั้งหมดของ Facebook Page ที่เชื่อมต่ออยู่ การดำเนินการนี้ย้อนกลับไม่ได้

ลบข้อมูลจาก Face Shelf

  1. เข้าสู่ระบบ Face Shelf ด้วย Facebook Page ที่ต้องการลบข้อมูล
  2. กลับมาหน้านี้แล้วกดปุ่ม “ลบข้อมูลทั้งหมด”
  3. ระบบจะออกจากระบบและแสดงรหัสยืนยันการลบ

Delete all Face Shelf data for the currently connected Page.

ถอนสิทธิ์จาก Facebook

ผู้ใช้สามารถถอนสิทธิ์ Face Shelf เพิ่มเติมได้ที่ Facebook Apps and Websites Settings

English: Sign in with the Facebook Page whose data you want to remove, return to this page, and select “Delete all data.” Face Shelf will permanently remove the encrypted Page token, sessions, imported posts, product images, and saved statuses associated with that Page.
